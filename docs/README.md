# CivicFlow – AI Powered Smart Complaint Management System

CivicFlow is an AI-powered smart complaint management system enabling citizens to report civic infrastructure issues (road damage, garbage, water leakage, street lights, electricity, drainage, traffic, pollution, public property).

## Project Structure

```
CivicFlow/
├── backend/    # Node.js + Express REST API (Port 5000)
├── frontend/   # Vite + React UI Application (Port 5173)
├── database/   # Supabase PostgreSQL schema and seed files
└── docs/       # Project documentation
```

## Running Locally

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
